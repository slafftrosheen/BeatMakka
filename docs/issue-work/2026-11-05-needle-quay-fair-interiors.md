## Saved shape and compatibility

`quay.fair = { clears = { targets = 0..3, bells = 0..3, rings = 0..3 }, prizes = { [listedPrizeId] = true } }` is additive to the current QuayProgress field. Missing fair data sanitizes to empty. Sanitization whitelists games/prizes, clamps clears and rejects ownership unsupported by earnings. `QuayProgress.equal` includes fair state; ProfileStore's existing capture/load, edit-version, delayed progress persist and explicit journal save retain it. No new top-level profile version or music migration is introduced. Existing side-game keepsakes remain intact. Fair knowledge is a bounded derived award in QuayIdentity, not a client XP grant.

No approved source assets or machine-readable asset register entries were changed. The required Windows source directory was refreshed at both the supplied path and `/mnt/c/...`; neither is mounted. The approved restored style board was inspected.
