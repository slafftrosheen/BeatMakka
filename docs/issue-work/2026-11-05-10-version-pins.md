# Ordinary music version pins and derived-copy integrity — #10/#15/#21/#22/#23

Base: `aa6cb5f`. The all-issue code audit found that release/remix copies pinned pack versions, while ordinary new/saved projects did not. A changed mapping could therefore reinterpret ordinary saved music, even though release playback refused it. This batch brings the same contract to ordinary authoring without inventing historical provenance.

New default projects store exact stable sample IDs, pack IDs and mapping revisions. New programs retain declared source-pack metadata when their assignments belong to one version. Ordinary instrument edits maintain pins for routed programs; explicit assignments add current identities. Shared transport distinguishes unavailable audio from version mismatch, and the personal audio diagnostic receives the stored pins. A live pad or Sound audition also checks its **captured** pins before triggering audio; a mismatched editor selection cannot bypass the transport simply because current bytes are locally available. Other independently validated schedules/world previews may still use that same current sample ID.

Existing documents are cloned before upgrade. A missing pin is reconstructed from a program's recorded pack/mapping metadata where that exists. Otherwise it is labelled `unverified`, not today's supposedly historical version. Current, archive, recovery and Finished Song containers retain their references and get descriptive version metadata; release records already carrying pins are not rewritten. Unknown or mismatched content is never swapped silently. Profile schema stays 4, music stays 2; earlier schema 3/music 1 and legacy imports still follow the existing upgrade/protection path.

An unfinished workspace with unverified historic versions offers **USE CURRENT PACK VERSIONS / ARCHIVE HISTORIC REFERENCES** in its shelf details. This explicit action checks ownership and full workspace context, archives the exact preimage, resolves only currently routed program assignments, updates unknown pins to available current versions, advances project/sequence/draft revisions, validates the complete profile budget and activates the new unsaved workspace. It does not modify an immutable Finished Song or override a known mismatched version. Open a Finished Song's editable copy to make a separate version. Removed/orphan pins and unused retained old kits cannot permanently block recovery after the player has replaced the active unavailable assignments; their original definitions remain in the archived preimage. Unavailable IDs still actually routed to a track cause refusal.

Joint jam snapshots now retain safe source attribution while withholding unrelated project names/private notes. Joint drafts and kept performance sections preserve original contributors and release/version lineage on their own musical objects. Later new arrangements and releases gather these dependency credits. Contributor/lineage capacity is bounded; nothing drops a name to make room. Jam/take materialization also merges stored version pins explicitly and refuses incompatible copies before any live mutation.

Jam entry now pauses the actual personal transport, including its saved cursor, instead of changing only the top-level UI flags. Leaving the jam cannot silently restart an older transport marked playing. No source pitch, tempo or saved project is overwritten by joining.

The chapter's old four-position metal and compulsory quarter-note I03 gates were also reconciled with the actual current saved Sound Hunt rules: two different saved metal positions and the earlier hunts plus two personal saved helper rhythms. Objectives, scene dialogue, journal text and text-only voice guidance now agree. The optional echo remains an exercise; existing completed flags and earned history remain intact. Existing recorded audio is preserved, and stale changed instructions remain text-only until replacement recording is separately authorized.

Source checks/review are the evidence boundary. No Luau compiler, pinned lint/build tools, Studio, actual audio, device, multiplayer or hosted save was available or run. No test suite/dependency/CI, content/binding change, upload, publishing or spending was added.
