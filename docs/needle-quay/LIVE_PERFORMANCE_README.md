# Needle Quay — Live Performance

Run Launch-NeedleQuay.cmd to install the bundled local content and open this demo. No publishing or account uploads are required. Saves remain session-only in this local demo.

## Performance controls
- Sixteen pads stay on the left. PERFORM on the right shows sixteen steps and six live knobs together: tone, drive, echo, space/reverb, level and pitch.
- Select a pad, toggle its numbered steps, then PLAY. Drag a dial vertically, use its +/- buttons, or scroll over it. REC, STOP and tempo are in the top strip.
- A/B/C/D, MUTE and SAVE sit below the pads. SOUND contains detailed sample editing; LIBRARY and SETUP remain secondary workspaces.
- STREET SPEAKER broadcasts the live pattern near your Roamer while you perform. It is off by default and stops on release, silence or departure. Other nearby players hear the distance-faded live pattern; your own workshop audio is not doubled.

## Musical neighborhood
Companion dance cycles and resident movement use the same server timestamp and tempo as playback. Pattern density and audible pad gain set movement energy. Drive adds a restrained bounce; echo/reverb add sway. Meaningful changes trigger short acknowledgements or applause with a cooldown. Silent and muted patterns do not drive dancing. Existing per-character safe motion limits remain in place.

The record shop and supply shop are 50% larger, cafe 35%, ferry booth 25%, and repair/signal shops 15%. Scaling is uniform, including doors and solid collision shells. Source models and authored dimensions remain preserved.
