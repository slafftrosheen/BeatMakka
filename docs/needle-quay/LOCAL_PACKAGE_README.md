Unzip the entire package. Run `Launch-NeedleQuay.ps1`, then press Play in Studio. The launcher verifies and installs only the local `needle-quay` content namespace. Rerun it after a Studio update. `-StudioExe <path>` selects an installation; `-InstallOnly` installs without opening Studio.

This revision includes 55 asset definitions, six human character revisions with local skinning, four ambient residents, the canonical Mica, a detailed camper adapted from the supplied model, modular skyline, café furniture, instruments, warm storefronts, foliage, harbor water and restrained environmental motion. All 184 local WAV bindings remain included. Use QUAY / MAP or M for the route journal; use the on-screen action button or E/X near an interaction.
