# Needle Quay / optional companions prototype

Extract the complete ZIP, run Launch-NeedleQuay.ps1, then press Play in Roblox Studio. The launcher verifies and installs only local companion content. The place remains unpublished.

Start Alone. Open Companions / Alone beside the map, or the Companions tab in the journal. Choose Alissia, Nikolas, or Alone. Hints are optional; A more specific hint reveals the next level only when requested. Choice saves for the current Studio Play session. A fresh Play starts with the default.

One local companion follows during exploration. It hides while editing at MK-I, using Stage, Listening, Jam, ChapterConcert or the journal. Effects OFF keeps text help and movement available while reducing decorative animation. The companion never plays or edits your music, collects sounds or awards progress.

The two original character models are DCC candidates with separate measured LODs, a 512 atlas, a 16-bone segmented rig and ten source clips. Their art is not approved. The current local follower uses procedural presentation poses; no Roblox animation assets were uploaded.

The repository contains the Russian artbook PDF, master sheets, Blender/GLB sources, production contract and developer handoff. Phone/gamepad, multiplayer, cloud conflict and full solo-route acceptance remain open. See docs/COMPANION_DEV_HANDOFF_RU.md and docs/evidence/issue-20-companions in the repository.


Updated from the supplied companion pack: Alissia has a three-page sound notebook; Nikolas has saved-beat observations for pulse, layers and chirp replies. Choose a page and use Talk for two optional lines about the current place. Notes do not award quests or edit music. The character card uses a static local 3D portrait, released when closed. Newly refined models remain candidates. The companion artbook is now v3.
