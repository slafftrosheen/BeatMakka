## Rebuild and delivery

Use the repository-pinned tools from the root:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python tools/adapt_user_quay_models.py -- --fresh
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python tools/polish_quay_hero_props.py --python tools/export_local_demo_meshes.py
python tools/package_local_demo_content.py
rojo build default.project.json --output output/needle-quay-demo/NeedleQuay-Artbook-Pass.rbxlx
python tools/package_needle_quay_demo.py --evidence-dir docs/evidence/needle-quay-polish-2
```

The character and sky source generators are `tools/build_quay_supporting_characters.py` and `tools/build_quay_sunset.py`; rerun the exporter/packager after changes to those sources. The package includes the tracked launcher. Unzip it completely, run `Launch-NeedleQuay.ps1`, then press Play in Studio. Companion files are required and must be reinstalled after Studio updates.
