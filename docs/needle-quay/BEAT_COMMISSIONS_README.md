# Needle Quay — Beat commissions

> Historical commissioning revision. Current requests evaluate a chosen named saved sequence and its saved revision. Use **Save Sequence**, wait for confirmation, then select that named sequence at the host. The Shelf/A–D submission instructions below are superseded by [MPC v3](MPC_V3_README.md); the older delivery evidence remains scoped to its original revision.

Run Launch-NeedleQuay.cmd from the extracted folder, then Play in local Studio.
Do not launch the PowerShell script directly. All content stays local; nothing is uploaded.

## Four requests
Meet Tori, Ivo, Naya or Mica and open their conversation. Each has a beat request after you discover its FX:
- Tori: Dock Echo, 95–135 BPM.
- Ivo: Vent Room, 105–145 BPM.
- Naya: Lantern Space, 70–105 BPM.
- Mica: Signal Repeat, 115–155 BPM.

Take a request. In your Roamer, use two audible pads and put the requested FX on a pad with at least four steps. The FX recipe may be adjusted slightly. Use the Sounds lesson if you need help. Store on Beat Shelf and Save; wait for confirmation. The request evaluates the active A/B/C/D pattern captured in the selected saved Shelf entry. Unsaved edits do not count.

Return to the host, choose Shelf 1–6 and press Play. There is an eight-second local audio loading window followed by one bar. Nearby street people acknowledge the listening session. The host responds to tempo, layers and FX settings; success triggers companion/street celebrations and a completion stamp. Try again freely. Finish all four to equip QUAY PRODUCER in the wardrobe. This new title has a text recognition line; existing companion hints/success voices are reused, and new host feedback is text.

Use Pause Request to return to the main campaign. Requests are optional; no genre restrictions or campaign gates were added. Replays give celebrations, not duplicate progress.

## Delivery boundaries
Built and packaged locally with pinned tools. No test suite or Studio playtest run for this change. Listening, UI layout, multiplayer and mobile acceptance remain unverified. Responses are authored rules applied to saved settings, not audio recognition or microphone analysis. Loading failure can make the excerpt silent; mission evaluation still uses saved settings. The excerpt is local to the submitting player; the existing nearby success celebration is shared. Studio progress lasts only for the current Play session.
