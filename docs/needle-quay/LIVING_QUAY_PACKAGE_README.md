# Needle Quay — supplied companions and living public spaces

Extract the complete ZIP. Double-click `Launch-NeedleQuay.cmd`, then press Play in Roblox Studio. The launcher installs the bundled local files and opens `NeedleQuay-LivingQuay.rbxlx`. It uses a process-only PowerShell execution-policy bypass; your saved system policy is unchanged. Nothing is uploaded or published.

Open Companions in the journal and select Alissia or Nikolas. Both now use the user's supplied textured GLBs. Their original skin weights are retained and their source idle/walk/run/cheer/clap clips are sampled for local presentation. The full original GLBs, including all source clips, are preserved in the repository. If local skin creation is unavailable, the exact textured body remains as a static follower fallback; inspect console output before treating animation as accepted.

The market has four covered produce counters and a clear central aisle. Cafe seating is moved off the main road into a garden court. Morrow Repairs has a laptop/radio bench and electrical cabinets. The waterfront gains grouped seating and planters. Resident walking routes now pass through the new gathering areas. Existing music controls, solo progression, mission targets and companion selection remain unchanged.

Source geometry: Alisija 10,295 triangles; Nikolas 10,968 triangles. No topology reduction was applied. The earlier 4,500-triangle authored target remains a future optimization decision, not a claimed pass. Each active companion uses two local skin chunks and a 1024-pixel texture.

This is a locally built implementation candidate. Rojo packaging succeeded; Studio Play, skin deformation, physical-device performance, multiplayer and cloud persistence were not tested in this revision. Older screenshots and runtime receipts do not establish acceptance of this package.

No provider generation, Roblox uploads, new dependencies or test suites. New props were extracted from the user's existing repository assets; originals and SHA-256 provenance are retained.
