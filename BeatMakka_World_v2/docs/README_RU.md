# BeatMakka / Frequency Zero — World Artbook v2.0

Готовый **проектный пакет** для согласования нового мира и дальнейшей разработки первой игровой главы. Создан 24.10.2026 на основе доступных подтверждённых материалов репозитория. Файлы не являются результатом реальной сборки/публикации Roblox и не изменяют `main`.

## Главные материалы

- **`../BeatMakka_World_Artbook_v2_RU.pdf`** — 32 визуальные страницы: лор, идея города, все 11 стилевых районов, начально закрытая карта, Needle Quay, фургон, прогрессия, музыкальное обучение, архитектура, арт-пайплайн и этапы приёмки.
- **`../BeatMakka_Needle_Quay_Development_Plan_RU.pdf`** — 18 страниц подробного инженерного плана: текущий статус, реальные ограничения, маршрут P1–P4, клуб, migration path, Luau модули, contracts, батчи B0–B8, тесты, Definition of Done и риски.
- **`DEMO_DEVELOPMENT_PLAN_RU.md`** — редактируемая исходная версия инженерного плана.
- **`CODEX_IMPLEMENTATION_BRIEF_RU.md`** — готовое следующее задание для первого B0+B1 batch.
- **`district_register.json`** — machine-readable 11 районов / стили / состояния / иллюстративные координаты, НЕ Roblox `Vector3`.

## Графика и исходники

Все графические материалы лежат в `../maps/` в **PNG + редактируемом SVG**:

1. `BeatMakka_City_Map_Initial_Locked` — первое открытие, Needle Quay доступен, 10 районов закрыты.
2. `BeatMakka_City_Map_District_Master` — полная художественная карта для внутреннего планирования.
3. `BeatMakka_Needle_Quay_Demo_Map` — четыре парковки, маршрут и финальный клуб.
4. `BeatMakka_LoopVan_Concept` — предложенный внешний силуэт фургона (не 3D-модель).
5. `BeatMakka_Restoration_States` — до/во время/после восстановления.

Регенерация исходников возможна по Python-скриптам в `../sources/`: `build_maps.py`, `build_diagrams.py`, `build_artbook.py`, `build_plan.py`. Используются локально доступные библиотеки `reportlab`, `weasyprint`, `mistune`, `cairosvg`, `scipy`, `shapely`. Текущие шрифты — системные, отдельные файлы шрифтов не входят в пакет.

## Что сохранено и что изменено

- Сохранён утверждённый Needle Quay style language: teal/cream/amber/coral/wood, четыре existing finishes, размеры и структура MK-I.
- Сохранён исходный 36-страничный артбук MK-I как авторитет для пэдов/инструментального UX. Эта новая редакция — **мировая часть v2.0** с обновлённым лором, картой и мобильным домом, не перезапись действующих исходников.
- Новый LoopVan-01 заменяет **роль домашнего пространства**, но H06 остаётся общественным магазином/мастерской; в плане указан поэтапный refactor с сохранением личных сохранений.
- Звуковые направления: original starter плюс 10 точных genres. На момент сверки 100/160 genre sounds имели Roblox IDs, 60 ждали загрузки; оригинальные 24 audio assets и private cloud acceptance не были завершены. План не объявляет несуществующий контент работающим.
- Замки районов не лишают игрока уже имеющихся стилевых звуков: это независимые концептуальные права.
